01 / GET STARTED

Start your local session.

GitHub Pages hosts this project page only. The proxy engine runs locally, so your browsing service is not exposed as a public proxy.

01

Install Node.js 20 or newer, then get the project files.

git clone https://github.com/Quran8to24/Web-Proxy.git
02

Install dependencies and start the local server from the project folder.

npm installnpm start
03

Choose “Open local proxy” above to open the browser workspace.
